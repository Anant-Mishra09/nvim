    Harpoon
     leader-a = adds a file to the harpoon list
     Ctrl-e = opens the menu
     Ctrl-p = goes to the previous file
     Ctrl-n = goes to the next file
     Leader-fl = open  telescope on the harpoon
     Leader-r = remove the current file from harpoon

    Git commands
    

    code complition
     Ctrl-space = manually opens auto-complete menu
     enter = selects the suggestion
     tab,shfit-tab = goes up or down in the menu
     leader-s = the toggle for on and off
    
    lsp commands
     Leader-e = shows diagnostics
     gd = go to definition
     Leader-ca = code action open availble fixes
     Leader-h = hover documenation displays information about the sysmbol under your cursor
    
    Neotree
     Ctrl-b = opens the bar on the left (might be a bit buggy with opening and closing)

    Telescope
     Leader-ff = find files ,for finding files
     Leader-fg = live grep  ,for searching inside files
     Leader-fb = telescope buffers
     Leader-fh = help tags
